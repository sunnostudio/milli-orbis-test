# ORBISTA 特設ページ計画

最終更新: 2026-11-10

> **イベント方針（2026-11-05）:** ORBISTA第一弾はお正月企画（Brand New Years 2027）として準備する。クリスマス企画は2026年の開催を見送り、2027年への延期を含めて時期未定。特設ページ内や共通キャンペーン表示に残るChristmas 2026の文言・設定は、後続作業でお正月企画に合わせて見直す。
>
> **現在の状態（2026-11-10）:** お正月企画は公式告知前のため、イベント名・日程・キャンペーン文言を公開ページに出さない。`data/campaigns.js` は空配列のまま維持し、季節テーマは開催期間内に自動適用する。ユーザー向けのテーマ切替UIは設けない。

## 1. 目的

ORBISTA を「一度きりの特設ページ」ではなく、Milli Orbis 全体を季節ごとに変える**イベントシリーズブランド**として定着させる。

- シリーズ共通の世界観（星・軌道・星座）を持つブランドハブを `/orbista/` に置く
- 各季節イベントは個別のテーマを持ち、シリーズとして積み上がる
- 開催期間中はポータル全ページに ORBISTA のキャンペーンバーを表示する
- 開催期間外でも、フッターとモバイルメニューから特設サイトへ到達できる

## 2. 情報設計

`/orbista/` は以下の順で構成する。

1. ヘッダー
2. 最新ニュースバー（最新1件 + 一覧へ）
3. ヒーロー（ORBISTA ロゴ + NEXT EVENT カード）
4. What is ORBISTA
5. News
6. Contents
7. Event Lineup
8. The Experience
9. Join
10. Related Sites
11. フッター

### ページの役割

- `/orbista/` … シリーズのブランドハブ。全イベントの入口とアーカイブ。
- `/orbista/brand-new-years-2027/` … お正月企画の個別イベントページ（内容・公開時期の確定後に検討）。
- ニュース … `news/?tag=ORBISTA` で ORBISTA 関連のみ表示。

## 3. 実装ファイル

| ファイル | 役割 |
| --- | --- |
| `orbista/index.html` | ブランドハブ本体。standalone。 |
| `orbista/orbista.css` | 専用スタイル。Milli Orbis の `style.css` は読み込まない。 |
| `orbista/assets/orbista-logo-600.webp` / `-1200.webp` | ヘッダー・フッター・ヒーロー用ロゴの軽量版。 |
| `data/campaigns.js` | 季節テーマの定義（表示期間・バー文言・トップページバナー）。 |
| `scripts/campaign-boot.js` | 描画前にテーマを決定し、レイアウトシフトを防ぐ。 |
| `scripts/campaign.js` | バー文言の差し込み、トップページバナーの表示。 |
| `campaigns.css` | キャンペーンバー・スポットライトのスタイル。 |
| `scripts/inject-campaign.js` | 全ページへのキャンペーン層の挿入・削除。 |

### ページ生成後の適用手順

`scripts/gen-pages.js` などでページを再生成した場合は、キャンペーン層を再挿入する。

```bash
node scripts/inject-campaign.js
```

キャンペーン層だけを外したい場合:

```bash
node scripts/inject-campaign.js --remove
```

挿入対象は `id="siteHeader"` を持つページ。ORBISTA 特設ページ、プレスリリース、halloween、dist は除外される。

## 4. 季節テーマの自動適用

### 表示テーマの決定

1. `campaign-boot.js` が `window.MILLI_CAMPAIGNS` を読み込む。
2. `enabled !== false` かつ、現在時刻が `start` 以上 `end` 未満の最初のテーマを選ぶ。
3. `html` に `data-campaign="<id>"` を付与する。該当がなければ `normal`。
4. `campaign.js` がキャンペーンバーの文言とトップページのスポットライトを差し込む。

ユーザー向けのテーマ切替UIは設けない。`localStorage` や URL パラメータによる上書きも行わず、表示テーマは開催期間だけで決まる。

### 現在のテーマ

- `normal` … キャンペーン期間外の通常表示。
- キャンペーンID … `data/campaigns.js` に登録したテーマ。開催期間内のみ自動適用。

※お正月企画（Brand New Years 2027）は告知前のため、`data/campaigns.js` に追加しない。ハロウィン2027など未告知のテーマも同様に追加しない。

### データ保護

- 切り替えるのは**表示テーマのみ**。`data.js` やニュース、イベントデータは変更しない。
- 表示設定を `localStorage` に保存しない。
- 開催期間を過ぎると自動的に `normal` に戻る。ユーザー側の操作は不要。

### イベントの追加方法

告知が可能になったイベントだけ、`data/campaigns.js` に以下を追加する。

```js
{
  id: "spring2027",
  label: "ORBISTA Spring 2027",
  shortLabel: "Spring 2027",
  start: "2027-03-01T00:00:00+09:00",
  end: "2027-04-01T00:00:00+09:00",
  enabled: true,
  bar: { label: "ORBISTA", text: "...", shortText: "...", href: "/orbista/" },
  spotlight: { eyebrow: "...", title: "...", desc: "...", href: "/orbista/", cta: "..." }
}
```

- `enabled: false` のテーマは自動選択されない。未告知テーマの下書きに使うが、公開リポジトリにイベント名や文言を置かない運用を優先する。
- ローカルで表示確認する場合は、一時的に `enabled: true` と現在時刻を含む開催期間を設定し、確認後に元へ戻す。
- `?campaign=` や `localStorage` によるプレビューは廃止した。

### 終了時

- 何もしなくても `end` を過ぎれば `normal` に戻る。
- 早期に止めたい場合は `enabled: false` にするか、エントリを削除する。
- バーだけ止めたい場合も `enabled: false` を使う。

## 5. ORBISTA ページの独立性

ORBISTA 特設ページは Milli Orbis 本体とは別の世界観を持つため、以下を読み込まない。

- `style.css`
- `script.js`
- `campaigns.css`
- 推し背景デコレーション（`page-deco`）

これにより、本体のカスタム背景や季節テーマの影響を受けない。
